# Temporal KG Evaluation Experiments

## Notebook

[Temporal_KG_Evaluation_V4_Final_Methodology_Colab.ipynb](./Temporal_KG_Evaluation_V4_Final_Methodology_Colab.ipynb) is an experimental evaluation notebook for the temporal knowledge graph. It records a methodology and analysis separate from the main extraction/entity-resolution/graph-construction workflow.

The notebook expects evaluation data and a Colab-compatible runtime as configured in its cells. Inspect its stated input paths and methodology before running; its outputs are experiment-specific and should not be confused with the final production graph or a general accuracy certification.
